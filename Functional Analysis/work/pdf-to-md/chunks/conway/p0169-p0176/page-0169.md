Thus it may be assumed that $T _ { k } ( x _ { 0 } ) \neq x _ { 0 }$ for all k, but $T _ { 0 } ( x _ { 0 } )   =   x _ { 0 }$ . Make this assumption.

By Lemma 10.7, there is an $\varepsilon   >   0$ and there is a continuous seminorm p on $\mathcal { X }$ such that for every $T$ in $\mathcal { S }$ and $1 \leqslant k \leqslant n ,$

$$
p ( T ( T _ { k } ( x _ { 0 } ) ) - T ( x _ { 0 } ) ) > \varepsilon .\tag{10.10}
$$

Let $\mathcal { L } _ { 1 } =$ the semigroup generated by $\{ T _ { 1 } , T _ { 2 } , \ldots , T _ { n } \}$ . So $\mathcal { L } _ { 1 } \subseteq \mathcal { L }$ and $\mathcal { S } _ { 1 } = \left\{ T _ { l _ { 1 } } \cdots T _ { l _ { m } } : m \geqslant 1 , 1 \leqslant l _ { j } \leqslant n \right\}$ . Thus $\mathcal { S } _ { 1 }$ is a countable subsemigroup of $\mathcal { S }$ Put $\vec{K} = \overline{\mathrm{co}} \left\{ T(x_0) : T \in \mathcal{S}_1 \right\}$ Therefore $K$ is a weakly compact convex subset of $Q$ and K is separable. By Lemma 10.2, there is a closed convex subset C of K such that $C \neq K$ and $p - \mathrm{diam}(K \backslash C) \leqslant \varepsilon.$

Since $C \neq K$ , there is an S in $\mathcal { S } _ { 1 }$ such that $S ( x _ { 0 } )   \in   K   \setminus   C$ Hence

$$
S ( x _ { 0 } ) = S T _ { 0 } ( x _ { 0 } ) = \frac { 1 } { n } \left[ S T _ { 1 } ( x _ { 0 } ) + \cdots + S T _ { n } ( x _ { 0 } ) \right] \in K \setminus C.
$$

Since C is convex, there must be a $k, 1 \leqslant k \leqslant n,$ such that $S T _ { k } ( x _ { 0 } )   \in   K \backslash C$ . But this implies that $p(S(T_k(x_0)) - S(x_0)) \leq p - \mathrm{diam}(K \setminus C) \leq \varepsilon,$ contradicting (10.10). This establishes Claim 10.9.

Let $\mathcal { F } = \mathrm { a l l }$ finite nonempty subsets of $\mathcal { L } ,$ If $F { \in } { \mathcal { F } }$ , let $Q_{F}=\left\{x \in Q: T(x)=x\right\}$ for all T in $F \}$ . By Claim 10.9, $Q _ { F } \neq \square$ for every $F$ in $\mathcal { F }$ . Also, since each T in $\mathcal { S }$ is weakly continuous and affine, $Q _ { F }$ is convex and weakly compact. It is easy to see that $\{ Q _ { F } : F \in { \mathcal { F } } \}$ has the finite intersection property. Therefore, there is an $x _ { 0 }$ in $\bigcap \{ Q _ { F } : F \in { \mathcal { F } } \}$ .
