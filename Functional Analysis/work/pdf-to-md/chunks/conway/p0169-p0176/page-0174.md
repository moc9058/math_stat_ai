## §12\*. The Krein-Smulian Theorem

Let A be a convex subset of a Banach space $\mathcal { X } .$ If A is weakly closed, then for every $r > 0,   A \cap \{ x \in \mathcal{X} : \| x \| \leqslant r \}$ is weakly closed; this is clear since each of the sets in the intersection is weakly closed. But the converse of this is also true: if A is convex and $A   \cap   \{ X   \in   \mathcal { X } :   \|   x   \|   \leqslant   r \}$ is weakly closed for every $r   >   0 .$ then A is weakly closed. In fact, because A is convex it suffices to prove that A is norm closed (Corollary 1.5). If $\{ x _ { n } \} \subseteq A$ and $\| x _ { n } - x _ { 0 } \| \to 0 ,$ then there is a constant r such that $\| x _ { n } \| \leqslant r$ for all n. By hypothesis, $A \cap \{ x { \in } { \mathcal { X } } : \| x \| \leqslant r \}$ is weakly closed and hence norm closed. Thus $x _ { 0 } { \in } A$

12.1. The Krein-Smulian Theorem. $\mathit { I f }   \mathcal { X }$ is a Banach space and A is a convex subset of $\mathcal { X } ^ { * }$ such that $A \cap \left\{ x ^ { \ast } { \in } { \mathcal { X } } ^ { \ast } { : } \parallel x ^ { \ast } \parallel \leqslant r \right\}$ is weak-star closed for every $r   >   0$ , then A is weak-star closed.
