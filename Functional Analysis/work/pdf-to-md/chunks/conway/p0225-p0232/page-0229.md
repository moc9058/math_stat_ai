## §7. The Spectral Theory of a Compact Operator

This Banach algebra has no identity, so if $A   \in   \mathcal { B } _ { 0 } ( \mathcal { X } )$ , then $\sigma ( A )$ refers to the spectrum of A as an element of (X).
