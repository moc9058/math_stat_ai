The Cantor set can be identified with the product of a countable number of copies of $\mathbb { Z } _ { 2 }$ and is thus a compact abelian group. Indeed, the product of a countable number of finite sets (with the discrete topology) is homeomorphic to the Cantor set, so that the Cantor set has infinitely many nonisomorphic group structures.
