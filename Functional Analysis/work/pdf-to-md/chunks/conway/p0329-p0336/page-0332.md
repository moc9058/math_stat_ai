If $h \in \mathcal { L } _ { + } ^ { \perp } ,$ then $\boldsymbol{h} = (A + i)f$ for a unique f in dom A. Hence $\| U h \| ^ { 2 } = \| ( A - i ) f \| ^ { 2 } = ( 2 . 5 \mathrm { a } ) \| A f \| ^ { 2 } + \| f \| ^ { 2 } = \| ( A + i ) f \| ^ { 2 } = \| h \| ^ { 2 }$ .
