The next result is from Putnam [1968].

6.8. Theorem. If $\lambda { \in } { \partial } \sigma ( A ) .$ , then either λ is an isolated point of $\sigma ( A )$ or $\lambda \in \sigma _ { l e } ( A ) \cap \sigma _ { r e } ( A )$

PrOOF. Suppose $\lambda { \in } { \partial } \sigma ( A )$ but λ is not a point of $\sigma _ { l e } ( A ) \cap \sigma _ { r e } ( A )$ Thus $A - \lambda \in \mathcal { P F }$ . By the preceding theorem, there is a $\delta   >   0$ such that $A - \mu \in \mathcal { P F }$ and dim ker $( A - \mu )$ and dim ran $( A - \mu ) ^ { \perp }$ are constant for $0 < | \mu - \lambda | < \delta .$ Since $\lambda { \in } { \partial } \sigma ( A )$ , there is a v with $0 < | \lambda - v | < \delta$ such that $A - v$ is invertible. Therefore ker $(A - \mu) = (0) = \mathrm{ran}(A - \mu)^{\perp}   for   0 < |\lambda - \mu| < \delta.$ But $A - \mu \in \mathcal { P F }$ for these values of $\mu$ and hence has closed range. It follows that $A - \mu$ is invertible whenever $0   <   | \lambda - \mu |   <   \delta$ This says that λ is an isolated point of $\sigma ( A )$
